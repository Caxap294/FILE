## Часть 6. Этика обратной связи
### 5 правил
1. Ругай код, а не человека.
2. Пиши конкретно строку, где ошибка.
3. Объясняй, почему из-за этого всё сломается.
4. Подсказывай, как исправить, или давай пример.
5. Обязательно сначала похвали за то, что работает.
